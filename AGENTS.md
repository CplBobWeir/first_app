# Project structure

This is a single-file web app. Keep `index.html` at the project root so GitHub
Pages can serve it. The root also contains `AGENTS.md`, `spec.md`, and
`prompts.md`.

Use the numbered folders for all other project files:

- `00_planning/` — planning notes and sketches.
- `01_data/` — data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in the appropriate root location or numbered folder. Add
files to the root only when they are one of the designated root documents or
are required for GitHub Pages; do not create extra project files at the root.

After each request, add an entry to `prompts.md` describing what was asked,
what changed, and whether it worked.
